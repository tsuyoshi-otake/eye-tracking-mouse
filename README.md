# eye-tracking-mouse

カメラでマウスを操作する Windows 用プログラムです。見た場所にカーソルがジャンプし、頭の小さな動きで微調整し、意識して長くまばたきするとクリックします。

Win32 上で動くネイティブ Rust で、実行ファイル1つだけ、GUI・画像処理・機械学習フレームワークは使いません。直接の依存は Microsoft の `windows` クレートのみです。キャプチャは Media Foundation、顔ランドマークモデルは Windows 標準の Windows ML 上で動かし、入力注入は `SendInput`、描画は GDI です。

## 状態

カメラの前に人がいなくても確認できるものは、すべて自動で確認済みです([動作確認](#動作確認)参照)。まだ試せていないのは、実際の顔を使ったライブループです。設定ファイルの速度やまばたき時間は調整が必要になると思うので、次の項目は自分で試すまでは未検証として扱ってください。

- キャリブレーションの最初から最後までの実行、および実行中のキャンセル
- キャリブレーション実行中の一時停止
- 実際のカメラ映像でのプレビュー
- ポインティングとクリックの操作感

## 動作環境

- Windows 11、x64。build 26300 で開発・テストしています。内蔵の Windows ML が ONNX opset 13 のモデルを読み込めない古い Windows では動きません。`--selftest model` で確認できます。
- 1280x720 で映像を出力できる USB カメラ。
- ビルドには MSVC ツールチェーンの Rust 1.85 以降。

## ビルド

```
cargo build --release
```

生成物は `target\release\eye-tracking-mouse.exe` です。モデルは exe に埋め込まれているため、他にインストールやコピーが必要なものはありません。

## インストール

```
pwsh -File scripts\build-installer.ps1
```

で Inno Setup 6.6 以降を使って `installer\setup.iss` をコンパイルし、`installer\out\eye-tracking-mouse-v<version>-setup.exe` を作ります。先にリリースビルドを済ませてください。インストールはユーザー単位で、昇格なしに `%LOCALAPPDATA%\Programs` へ入り、スタートメニューに登録されます。アンインストールはプログラムファイルとショートカットを削除し、`%APPDATA%\eye-tracking-mouse`(設定・キャリブレーション・ログ)はそのまま残します。

## 起動

`eye-tracking-mouse.exe` を起動します。ウィンドウは表示されず、通知領域に目の形のアイコンが出ます(見えないときは `^` の中を確認してください)。開始したことは通知で知らせます。アイコンの色とツールチップに、プログラムの状態が表示されます。

| 操作 | 結果 |
|---|---|
| 頭を少し回したりずらしたりする | カーソルが動きます。速い動きほど大きく動きます。 |
| 両目を0.4秒ほど閉じて「どうぞ」と言われたら開く | 目を閉じた時点のカーソル位置で左クリック。「クリックしました」と言います。 |
| 目を閉じたまま1.5秒を超える | クリックは取り消され、「取り消しました」と言います。 |
| 目が細まるほど下を見る | 「どうぞ」のあと「取り消しました」。クリックは起きず、約3秒後にカーソルが再び動きます。かなり下を向いている間はまばたきクリックが使えません。 |

フレーズは Windows 標準の日本語音声で読み上げられます。日本語音声がない環境では、3種類のトーン(高・より高・低)が代わりになります。

| キャリブレーション後、カーソルから遠い場所に視線を止める | カーソルがそこへジャンプします。 |
| 実際のマウスを動かす | プログラムはすぐ手を放し、操作が止まってから1.5秒後に再び制御します。再開の前にカーソルを1ピクセルだけ動かして、動かせるかを確かめます。 |
| Mouse Without Borders などでポインターが別のPCにある | 上の確かめが届かないので、制御を再開しません。届くまで1.5秒ごとに1ピクセル(右と左を交互に)試すだけです。ポインターがこのPCに戻ると自動で再開します。 |

頭でのポインティングとまばたきクリックはすぐ使えます。視線ジャンプには先に[キャリブレーション](#キャリブレーション)が必要です。

### ポインティングの方式: head、eye、hybrid

アイコンのメニューの3つの項目「頭で動かす(遠くを見るとジャンプ)」「視線で動かす(eye tracking)」「視線で動かし、頭で微調整(ハイブリッド)」で、カーソルを動かすものを選びます。順に `head`、`eye`、`hybrid` で、使っているものにチェックが付きます。

`hybrid` では、視線がカーソルを運び(`eye` と同じ)、頭の小さな動きがそこからカーソルをずらします。視線の推定が数十ピクセルずれていても、的を見たまま頭を少し振って合わせられます。視線が別の場所へ移る(カーソルを `jump_distance` ピクセル以上運ぶ)と、ずらした分は消えます。キャリブレーションは3つのモードで共通です。

切り替えはその場で効き、`settings.txt` の `pointing` の行にも書き込まれるので次回の起動でも同じです(ほかの行やコメントはそのまま残ります)。`settings.txt` の `pointing` を直接書き換えても選べます。

| 値 | 動き |
|---|---|
| `head`(既定) | 上の表のとおり。頭の動きでカーソルを動かし、遠くを見ると視線ジャンプで飛びます。 |
| `eye` | 視線の推定位置がそのままカーソルの位置になる、連続追従の eye tracking です。見ている場所へカーソルが付いていき、見つめている間はほぼ止まります。 |
| `hybrid` | 視線がカーソルを運び、頭の小さな動きでそこから微調整します。別の場所を見ると微調整した分は消えます。 |

`eye` と `hybrid` を使うには[キャリブレーション](#キャリブレーション)が必要です。まだない状態でどちらかを選ぶと、通知でそう知らせます。キャリブレーションがない間は頭の動きだけでカーソルを動かします。`eye` では頭での微調整と視線ジャンプ(`gaze_jump`、`jump_distance`)は使われません。`hybrid` では視線ジャンプは使われず、`jump_distance` は微調整が消える距離として使われます。まばたきクリックと、実際のマウスを動かしたときに手を放す動作は、どちらの方式でも同じです。

見つめている場所でカーソルが震えるときは `eye_steadiness`(0.5〜8、既定 1.5)を大きくします。大きいほど震えず、視線を移したときの追従は少し遅くなります。

### ホットキーとメニュー

| キー | メニュー項目 | |
|---|---|---|
| Ctrl+Alt+P | 一時停止 / 再開 | 一時停止中はカメラを解放します。 |
| Ctrl+Alt+C | キャリブレーション / キャリブレーションを中止 | キャリブレーションの開始、または実行中のキャンセル。 |
| | カメラのプレビュー | カメラの映像と、顔に検出した点を表示・非表示。 |
| | 頭で動かす / 視線で動かす / 視線で動かし、頭で微調整 | `head`、`eye`、`hybrid` を選びます。すぐ反映され、設定ファイルにも保存されます。 |
| | 設定ファイルを開く | 設定ファイルをメモ帳で開きます。 |
| Ctrl+Alt+Q | 終了 | 終了します。 |

アイコンを右クリックまたは左クリックするとメニューが出ます。キーの組み合わせが他のプログラムに使われている場合は通知で知らせ、メニュー項目はそのまま使えます。

## キャリブレーション

1回の実行は1分半ほどです(記録が約1分、そのあとの確認テストが約30秒)。

1. 実際に使う姿勢で座り、キャリブレーションしたい画面にマウスポインタを置きます。その画面が対象になります。
2. Ctrl+Alt+C を押します。その画面を暗いページが覆い、手順を案内します(一時停止中でも解除されます)。
3. 中央の点を見ます。目を開け、頭を動かさず、点が進むまで待ちます。
4. 目だけで点を追います。頭は動かさないでください。点は中央のあと、画面の端ぎりぎりまで並んだ縦5×横5の格子を上の段から1段ずつ左右に折り返しながら回ります(中央を除く24か所)。記録中は周りのリングが閉じていきます。点が現れてから1秒は移動の時間で、そのあとの約1秒を記録します。まばたきや、目がまだ点に着いていなかった瞬間は自動で除かれます。
5. 再び中央の点を見て、頭を左右・上下にゆっくり回し、点のリングが閉じるまで続けます。
6. 確認テストです。格子にはなかった12か所に点が順に出るので、目で追います。1か所ごとに、プログラムが「ここを見ている」と推定した位置が丸で出ます(緑=命中、オレンジ=外れ。命中は画面の短辺の8%以内)。最後に「命中 n / 12、平均のずれ 約nピクセル」が4秒表示されます。
7. ページは自動で閉じます。通知にキャリブレーション完了と、確認テストで測った平均のずれ(ピクセル)または失敗理由が出ます。

確認テストの途中で顔が映らなくなったり止まったりしても、キャリブレーション自体は保存されます(そこまでに測れた分がずれの値になります)。

確認テストで記録した分も補正に使われます。保存されるモデルは、格子の25か所に加えて確認テストの場所でも合わせ直したものです。通知に出るずれは合わせ直す前の値なので、実際のずれはそれより小さくなります(実測では、合わせ直しに使わなかった場所で 163 → 116 px、121 → 112 px)。

Esc または Ctrl+Alt+C でキャンセルできます。顔が5秒間映らない、1ステップが25秒を超える、カメラの供給が止まる、モニター構成が変わる、一時停止する、のいずれかでも理由を告げて終了します。

結果は `calibration.txt` に保存され、次回起動時も使われます。以前の版で作った `calibration.txt` は読めないので、起動時にそう知らされたらキャリブレーションし直してください。カメラ・モニター・座る位置を変えたらキャリブレーションし直してください。

## 終了・停止

- 終了: Ctrl+Alt+Q、アイコンのメニューの「終了」、または `eye-tracking-mouse.exe --quit`。
- 終了せずすぐカーソルを取り戻す: 実際のマウスを動かすか、Ctrl+Alt+P で一時停止。

## 設定とファイル

すべて `%APPDATA%\eye-tracking-mouse\` に置かれます(`--data-dir` で変更可):

| ファイル | |
|---|---|
| `settings.txt` | 初回起動時に全設定と説明をデフォルト値で書き出します。読み込みは起動時のみ: 変更したら終了して起動し直してください。プログラムが書き換えるのは、メニューで切り替えたときの `pointing` の行だけです。 |
| `calibration.txt` | 最後に成功したキャリブレーション。顔の形と視線の画面への写し方を表す数値です。 |
| `log.txt` | 前回起動以降にプログラムが行ったこと。テキストのみ。 |
| `calibration-record-<時刻>.txt` | `settings.txt` で `calibration_record = on` にしたときだけ、キャリブレーションのたびに1つ作られます。各フレームで計測した顔の点の座標と、そのとき表示していた点の位置です(数値のみ、1回で数MB)。視線推定の精度を調べるためのもので、プログラム自身は読みません。不要になったら削除してください。 |

`settings.txt` では、カメラ番号、ポインティングの方式(`pointing`、`head` か `eye` か `hybrid`)と `eye`・`hybrid` のときのカーソルの保ち方(`eye_steadiness`)、`hybrid` のときの頭の動きに対するカーソルの速さ(`hybrid_head_speed`、20〜5000、既定450。微調整用で、すばやく動かしても速くなりません)、視線ジャンプとまばたきクリックのオン/オフ、頭の遅い・速い動きに対するカーソル速度(`head_speed_slow`、`head_speed_fast`)、静止カーソルの保ち方(`head_steadiness`、0.5〜8、既定2: 大きいほど穏やか)、最短ジャンプ距離(`jump_distance`)、まばたきクリックの各値(`blink_hold`、`blink_limit`、`blink_closed`)を設定できます。

`settings.txt` は初回起動時に一度だけ書き出されます。以前の版が作ったファイルには `pointing` と `eye_steadiness` の行がありません。`pointing` はメニューで切り替えたときに末尾へ書き足されます。`eye_steadiness` を変えるときは自分で書き足してください(ない間は既定値で動きます)。

## コマンドライン

```
eye-tracking-mouse [options]

  (no options)          run in the notification area
  --camera <index>      use this camera (see --list-cameras) instead of the one in the settings file
  --data-dir <folder>   keep the settings, the calibration and the log in this folder
  --quit                ask the running program to quit and wait until it has
  --list-cameras        print the attached cameras and exit
  --selftest <name>     run one check and exit: camera, face, model, pointer
  --image <file.bmp>    with --selftest face: use this picture instead of the camera
  --diag <seconds>      print what the face tracker measures, once per second
  --help                print this text
```

終了コード: 0 = 成功、1 = 未達(チェック失敗・起動済み・終了対象なし)、2 = エラー。

コンソールなしでビルドされているため、PowerShell は出力をパイプしない限り待ちも表示もしません:

```
.\target\release\eye-tracking-mouse.exe --list-cameras | Out-Host
```

デスクトップセクションあたり1インスタンスだけが動きます。2回目の起動は1つ目に伝えて終了します。

```
cargo test                                # ユニット・シミュレーションテスト。カメラ・顔・デスクトップ不要
cargo clippy --all-targets -- -D warnings
cargo test --test resident -- --ignored   # 実際のプログラムを一瞬だけ起動(存在しないカメラを指定)
```

最後のものは通知、プレビューウィンドウ、一瞬のキャリブレーションページを表示しますが、ポインターには触れません。

実行環境のチェック(PowerShell では `| Out-Host` を付けてください):

| コマンド | 確認内容 |
|---|---|
| `--selftest model` | 埋め込みモデルがこの Windows で読み込め、リファレンス出力を再現するか。 |
| `--selftest camera` | カメラが 1280x720 を十分な速さで出力するか。数秒間カメラをオンにします。 |
| `--selftest pointer` | カーソル移動とクリックが指定位置に正確に届くか。実際のカーソルを1秒ほど動かし、自分のウィンドウを1回クリックします。 |
| `--selftest face` | 顔が見つかり計測できるか。カメラ、または `--image` の画像で。数値のみ出力します。 |
| `--diag <秒数>` | トラッカーの計測値を1秒ごとに表示。設定調整用。 |

## 既知の制限

- 視線推定は粗く、良くて数十ピクセル、画面端ではさらにずれます。そのため視線はカーソルを近くへ運ぶだけに使い、細かい操作は頭に任せる設計です。
- 視線ジャンプはキャリブレーションした画面でのみ動きます。頭での移動はすべての画面で使えます。
- `pointing = eye` もキャリブレーションした画面でのみ動き、その画面の外を見ている間カーソルは止まります。カーソルの精度は視線推定の精度そのもの(数十ピクセル)で、頭で微調整することはできません。小さなボタンを狙うには `hybrid` か `head` が向いています。
- `pointing = hybrid` の頭での微調整は、シミュレーション上の人でしか試していません。視線の推定が大きくずれる場所では、そのぶん毎回頭で直すことになります。
- `pointing = eye` の滑らかさを決める定数はシミュレーションで選んだもので、実際の顔ではまだ試していません。
- 左クリックのみ: 右クリック、ドラッグ、スクロールはありません。
- 管理者権限で動くプログラムのウィンドウは、このプログラムが非特権で動いている間は注入した入力を拒否します。その間ツールチップは「カーソルを動かせません」と表示します。
- ホットキーは固定です。AltGr が Ctrl+Alt になるキーボードレイアウトでは、AltGr+P・C・Q で入力する文字はこのプログラムが取ります。
- アイコンのメニューを開いている間、プログラムはホットキー以外に反応しません。
- 設定は起動時にだけ読まれます。メニューから変えられるのは `pointing` だけで、ほかの値は `settings.txt` を編集して起動し直します。プログラムの動作中に `settings.txt` を編集していて、保存前にメニューで切り替えると、エディター側の保存がその切り替えを上書きします。
- ログオン時の自動開始は用意しておらず、試してもいません。

## プライバシー

カメラの映像はメモリ上で処理され、その場で捨てられます。ディスクに書き込まれることも、マシンの外に出ることもありません(ネットワークコードを含みません)。プレビューは画面に表示するだけです。`calibration.txt` には顔に関する数値が入りますが、上記のフォルダーに留まります。`calibration_record = on`(既定は off)にした場合の記録ファイルも同じで、入るのは顔の点の座標だけです。`pointing_record = on`(既定は off)にすると、動作中の毎フレームの数値(頭の向きと位置、目の信号、視線の推定位置、カーソルの位置とカーソルへの指示)が `pointing-record-<時刻>.txt` に残ります。書き出すのは一時停止・終了のときと10分ごとで、こちらも画像は含まず、プログラム自身は読みません。カーソルの動きがおかしいときに原因を調べるためのものなので、不要になったら削除してください。

## ソース構成

```
src/app       プログラム本体: tray アイコン、ワーカースレッド、キャリブレーションページ、プレビュー、設定、文言
src/platform  Win32 / WinRT の境界: カメラ、推論、ポインタ、ウィンドウ、描画、音声
src/control   純粋な判定: キャリブレーション手順、視線モデル、頭ポインティング、視線ポインティング、まばたきクリック
src/vision    顔ランドマーク上の純粋な幾何: 切り出し、頭部姿勢、目の特徴
tools/model   TFLite から ONNX への変換と比較の記録
```

依存は下向きのみで、`control` と `vision` はシステムに触れません。そのため判定ロジックはカメラ・顔・デスクトップなしでテストできます。
